# AlumFrame — FreeCAD Aluminum Profile Frame Generator

[中文](README.md) | [English](README_EN.md)

A FreeCAD workbench for quickly building parametric aluminum extrusion
frames, with automatic BOM (including per-member drilling/tapping
coordinates) and dimension annotations.

---

## Features

| Feature | Description |
|---------|-------------|
| Parametric frame | Edit the `Parameters` spreadsheet → geometry / annotations / BOM update live |
| Automatic BOM | Summarized per profile, with drilling coordinates for every member |
| Dimensions | `Measure::MeasureLength` annotations incl. post spacing, clearance, overall size |
| Edit existing frame | Select the Frame → Edit Frame; the panel pre-fills current parameters |
| CSV export | Export the BOM to CSV for purchasing |
| Chinese / English UI | Menus / panel / messages / **BOM / drawing text** follow FreeCAD's language (see `i18n.py`) |

| 40x40 | square tube | M8 | M10 |
| 60x60 | square tube | M10 | M12 |

### Profile resources

The dropdown only lists **regular sections**:

- **Parametric standard T-slot series** (E1515/E2020/E2020t/E3030/E4040/E4040t/
  E2040/E2060/E2080/E3060/E4080), generated by
  `profiles/extrusion_profiles.py` from public standard dimensions;
- **Plain square tubes** (20x20 / 30x30 / 40x40 / 60x60).

> DXF-derived profiles (hfs8 / nefs8 / nfs5 / nfsl8 ...) are **no longer
> registered** because of irregular exports/shapes. The parser
> (`profiles/dxf_parser.py`) and resources are kept for reference only.

#### Parametric standard profiles (recommended, no DXF needed)

Since some DXF exports are not clean, the project ships a **parametric
T-slot section generator** (`profiles/extrusion_profiles.py`) that builds
closed sections directly from public standard dimension tables
(outer contour + center bore + corner bores, with 45° ribs/notches):

| Series | Section | Notes |
|--------|---------|-------|
| E1515 | 15x15 | |
| E2020 / E2020t | 20x20 | standard / grooved |
| E3030 | 30x30 | |
| E4040 / E4040t | 40x40 | standard / grooved |
| E2040 / E2060 / E2080 | 20x40 / 20x60 / 20x80 | rectangular |
| E3060 | 30x60 | rectangular |
| E4080 | 40x80 | rectangular |

- Dimension tables reference the public industry data of the open-source
  **NopSCADlib** (`extrusions.scad`, GPL-3.0); the geometry is rebuilt with
  FreeCAD Part booleans.
- Square and rectangular series are both selectable, shown as e.g.
  `40x40 E4040`, `20x40 E2040`.
- **Rectangular orientation convention**: the first section size is
  "horizontal", the second is "vertical". Posts: first size along frame X,
  second along Y. X/Y beams: horizontal = first size, vertical = second size
  (e.g. a 20x40 beam is 20 wide × 40 high).

## Frame geometry rules

```
Origin: center of the frame base (0, 0, 0)
Z axis: up
Frame outer bounds: X = ±L/2,  Y = ±W/2,  Z = [0, H]
```

- Z posts sit at the four outer corners; the post outer corner aligns with
  the frame corner.
- X beams butt against the inner faces of the posts
  (length = L − 2 × section width).
- Y beams butt against the inner faces of the posts
  (length = W − 2 × section width).
- Section centers are flush with the post section center
  (beam Z baseline = 0, not centered on section height).

## Connection methods and machining

Pick a joint process in the task panel's **Connection** dropdown; the addon
**actually cuts holes in the solids** and writes tap sizes, depths, hole
positions and hardware into the BOM (hardware quantities are totaled).

| Method | Machining | Notes |
|--------|-----------|-------|
| Corner bracket + T-nut | none | Bolt slides into the slot; BOM lists bracket/bolt/nut |
| End tap + side through | beam end tap + post through hole | default, most common |
| Hidden connector | beam end tap + beam side access + post through | no visible hardware |
| Through tap | beam end through + post through | with a nut in the slot |
| Anchor connector | beam slot anchor hole + post through | anchor inserted in the slot |
| Straight joint / rod | beam end taps | for coaxial segmented beams/posts |
| Base / top plate | post top/bottom end taps | to fix base and top plates |

- Hole positions are computed from the current **section orientation**
  (post direction / beam vertical) and layer heights.
- **Tap sizes are matched to the actual center bore** (the bore is the tap
  pilot hole): E1515→M4, E2020/20x40/60/80→M5, E3030/30x60→M8,
  E4040/40x80/E4040t→M12; DXF profiles use the parsed bore; solid square
  tubes are binned by section size.
- **Through holes are clearance holes** (nominal + ~1 mm, e.g. M12→Ø13.5)
  so the bolt passes.
- **Hidden/anchor access holes are single-sided** (top face, depth =
  half section + 1), not through the whole section.
- **Through tap** drills the beam end transversely (perpendicular to the
  beam axis) plus a nut in the slot; the post gets a clearance through hole.
- Tap holes are cut as pilot holes and labeled with the tap size in the BOM;
  when the center bore ≈ pilot diameter there is no visible change in the
  solid (normal — threads are not modeled).
- **Hole parameters are editable in the panel**: diameter / depth / offset
  from the end (0 = profile default); **the diameter limit is half of the
  smaller section side** and is clamped automatically (e.g. Ø30 input on
  40x40 → Ø20).
- **BOM machining notes include position and direction**: taps note
  "both ends, 1 per end, 2 per member"; drilled holes note the distance from
  the end face, direction (along/transverse to the beam axis, downward from
  the top), diameter and depth; posts list the z height of each layer and
  the hole count per layer.

## TechDraw shop drawings

With "Create TechDraw drawing" checked, one **TechDraw page** is created with
**one row per profile type** (X beam / Y beam / Z post):

- Built-in **A2 landscape border template**
  (`templates/A2_Landscape.svg`, 594×420): text and views stay inside the
  inner frame (22 mm margin) and **avoid the bottom-right title block**;
- **All text annotations are left aligned** (Chinese UI): ASCII inside
  annotations is converted to full-width (equal advance) and each block gets
  a trailing rule of identical width, so all blocks share one X and the
  exact same left edge (measured 22.01 mm); in the English UI the
  annotations are already equal-width ASCII and align directly;
- **Title block fields filled automatically** (Chinese labels): profile
  (e.g. `40x40 E4040`), scale (e.g. `1:2.3`), sheet, material, connection;
  values are baked into a per-frame template copy
  (`~/.cache/AlumFrame/A2_*.svg`) so both the TechDraw page and the exported
  PDF show them; no separate top title;
- **A single scale for all profiles** (derived from the longest member and
  row height) so lengths are directly comparable; the scale value is shown
  in the title block;
- **All members are aligned on one end** (left end fixed at 22 mm from the
  border); the right end stays inside the frame;
- Main-view line width thins automatically for very long members; **end
  views are 1:1 detail views** so T-slots/holes stay legible on 20 m parts;
- "Export Drawing PDF" merges content with the template, producing a PDF
  **with border and title block**;
- Validated over the full length range 200 / 300 / 500 / 800 / 1000 / 1500 /
  2000 / 3000 / 4000 / 6000 / 8000 / 10000 / 15000 / 20000 mm: no overflow,
  left alignment and common scale preserved;
- Each member is placed with its **longest side horizontal** (X view not
  rotated, Y/Z views rotated 90°); end views use the same scale (clamped if
  needed);
- **Automatic dimensions** (above the main view, close to the member):
  - length = distance between the two end-face edges (e.g. `1040`);
  - holes use a single dimension chain: **both end faces → nearest hole
    center** (e.g. `20`/`20`) + **center distance between adjacent holes**
    (e.g. `230`/`230`); everything else is derivable;
  - every dimension value is verified after creation (`getRawValue` vs the
    expected value; mismatches are deleted);
  - sub-element names are resolved via `getEdgeByIndex` / `getVertexByIndex`
    (model coordinates) instead of guessing name order; placement
    compensates TechDraw's export offsets and avoids the frame/title block;
- Text annotations: part, **profile, length, quantity**, material,
  connection method, **machining** (position/direction/diameter/depth);
- **Drawing text follows the UI language**: title block (drawing title,
  profile, scale, sheet, material, connection), annotations and dimension
  text are emitted in Chinese or English by `i18n.py`; the English
  annotations stay aligned using their naturally equal-width ASCII glyphs;

Page objects use the `TD_` prefix; regeneration safely unbinds views, deletes
views, then deletes the page.

## Machining (default end-tap method)

### X / Y beams (horizontal)

**Taps at both ends**: M6↔M12 (per series), 2 per beam (high end + low end),
depth = 1.5 × diameter.

### Z posts (vertical)

**Cross through hole per layer**: one in X and one in Y direction; the bolt
passes and is locked with a nut.
**Taps at top/bottom ends**: to fix base/top plates (created with the
"Base / top plate" method).

  end1: M6 0 mm from the end face, 9 mm deep  (x=0, y=10, z=10)
  end2: M6 560 mm from the end face, 9 mm deep  (x=560, y=10, z=10)

Y-纵梁:
2 taps per member (along the beam axis), section center
  end1: M6 0 mm from the end face, 9 mm deep  (x=10, y=0, z=10)
  end2: M6 360 mm from the end face, 9 mm deep  (x=10, y=360, z=10)

Z-立柱:
Z post, 3 layers: M5 cross through hole per layer, M6 taps top/bottom

## Parameters spreadsheet

Each generated frame creates a `Parameters` spreadsheet as the **single
source of truth**:

| Cell | Meaning | Example |
|------|---------|---------|
| B1 | Profile | 20x20 |
| B2 | Profile width (mm) | 20 |
| B3 | Outer length X (mm) | 600 |
| B4 | Outer width Y (mm) | 400 |
| B5 | Outer height Z (mm) | 500 |
| B6 | Z layers | 1 |
| B7 | Material | Aluminum 6061 |

> Editing B3 (length) etc. updates geometry/annotations live, no rebuild
> needed. Editing the Frame group properties also syncs the sheet
> (two-way channel).

## Installation

```bash
# 1. Clone into the FreeCAD addon directory (FreeCAD 1.1 user dir example)
git clone git@github.com:gdbdzgd/AulmFrame.git \
    ~/.local/share/FreeCAD/v1-1/Mod/AlumFrame

# or create a symlink (development mode)
ln -s /path/to/repo ~/.local/share/FreeCAD/v1-1/Mod/AlumFrame
```

> The addon uses FreeCAD's **modern namespaced layout**
> (`freecad/AlumFrame/`, `init_gui.py` entry, no `sys.path` changes) and
> requires **FreeCAD >= 1.1** (see `<freecadmin>` in package.xml).

Restart FreeCAD; the toolbar/menu shows the **Aluminum Frame** commands:

| Command | Description |
|---------|-------------|
| New Frame | Open the generator and create a new frame (profile, orientation, connection, drawing options) |
| Edit Frame | Load the selected/current frame parameters and rebuild in place |
| Export BOM (CSV) | Export the current frame BOM (machining notes + hardware) to CSV |
| Create TechDraw Drawing | Regenerate the shop drawing for the current frame (one row per profile with quantity and machining) |
| Export Drawing PDF | Export the A2 drawing PDF with border/title block |

> Restart FreeCAD (or reload the workbench) after editing the addon code.

## Usage

### Create a frame

1. Open FreeCAD and switch to the **AlumFrame** workbench
2. Click **New Frame**, enter parameters, click Generate
3. Geometry + BOM + annotations are generated automatically

### Edit an existing frame

1. Select any frame part (beam or post)
2. Click **Edit Frame** (or menu AlumFrame → Edit)
3. The panel pre-fills the current parameters; editing and clicking Generate
   rebuilds in place

### Export BOM CSV

```python
from AulmFrame.bom import export_bom_csv
export_bom_csv(beams, '/tmp/bom.csv', material='Aluminum 6061',
               hole_spec={'beam_cross': 'M5', 'post_tap': 'M6'},
               profile_size=20)
```

## Technical limitations

- The BOM is static text; after editing the Parameters sheet directly,
  refresh via the panel "Generate" (edits made through the panel sync
  automatically)
- No partial posts (fixed topology: 4 posts / integer layers)
- The dropdown only offers parametric standard series and plain square
  tubes; DXF profiles were removed (parser kept for reference)
- Parametric beams use `Part::Extrusion` (**sketch driven**): the section
  sketch lives inside the "Frame" group, named `X-横梁 截面` etc.;
  double-click to edit it in Sketcher and all array copies update; holes are
  kept as `Part::Cut` on top of the base and survive recompute
- The array source base (`X-横梁(阵列源)`) is hidden by default, otherwise a
  beam would appear in the middle of the frame; edit the section sketch
  above to change the shape (or rebuild via the panel)
- Hole boolean results `XBeamBase_Cut` / `YBeamBase_Cut` / `ZPostBase_Cut`
  and the hole tools `*_Holes` are hidden by default (geometry dependencies
  only, not for display)
- Connection hole parameters are generic values (e.g. hidden connector side
  hole 18 mm from the end, anchor hole 15 mm); adjust in the `params` of
  `connections.py` for your actual hardware
- TechDraw projection of complex sections is slow; the first drawing
  generation/rebuild may take tens of seconds
- The UI (menus, task panel, messages) and the BOM/drawing text switch
  between Chinese and English according to FreeCAD's language setting
