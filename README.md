# AlumFrame — FreeCAD 铝型材框架生成器

[中文](README.md) | [English](README_EN.md)

FreeCAD 工作台插件，用于快速创建参数化铝型材方管框架，自动生成 BOM（含每根型材打孔/攻丝坐标）和尺寸标注。

---

## 功能概览

| 功能 | 说明 |
|------|------|
| 参数化框架生成 | 改 Parameters 参数表 → 几何/标注/BOM 实时联动 |
| 自动 BOM | 按型材规格汇总，含每根型材打孔坐标说明 |
| 尺寸标注 | `Measure::MeasureLength`，含柱距/净空/总外形 |
| 编辑已有框架 | 选中 Frame → Edit Frame，面板预填当前参数 |
| CSV 导出 | BOM 可导出 CSV，方便采购 |
| 中英文界面 | 菜单/面板/提示/**BOM/图纸文字**跟随 FreeCAD 语言设置（中文或 English），见 `i18n.py` |

## 支持的型材规格

| 规格 | 截面 | 十字通孔 | 攻丝 |
|------|------|---------|------|
| 20x20 | 方管 | M5 | M6 |
| 30x30 | 方管 | M6 | M8 |
| 40x40 | 方管 | M8 | M10 |
| 60x60 | 方管 | M10 | M12 |

### 型材资源说明

下拉中只提供**规整截面**：

- **参数化标准 T 型槽系列**（E1515/E2020/E2020t/E3030/E4040/E4040t/E2040/
  E2060/E2080/E3060/E4080），由 `profiles/extrusion_profiles.py` 按公开标准尺寸
  生成；
- **普通方管**（20x20 / 30x30 / 40x40 / 60x60）。

> 早期从 `profiles/dxf/` 解析的 DXF 轮廓型号（hfs8 / nefs8 / nfs5 / nfsl8 等）
> 因导出不规范、形状不规整，**已不再注册为可选项**。相关解析代码
> （`profiles/dxf_parser.py`）与资源文件仅作参考保留，不参与型号下拉。

#### 参数化标准型材（推荐，不依赖 DXF）

由于部分 DXF 导出并不规范，项目内置了**参数化标准 T 型槽截面生成器**
（`profiles/extrusion_profiles.py`），按公开的行业标准尺寸表直接生成闭合截面
（外轮廓 + 中心孔 + 四角孔，含 45° 加强筋/卡口），不再依赖外部 DXF：

| 系列 | 截面 | 说明 |
|------|------|------|
| E1515 | 15x15 | |
| E2020 / E2020t | 20x20 | 标准 / 带凹槽 |
| E3030 | 30x30 | |
| E4040 / E4040t | 40x40 | 标准 / 带凹槽 |
| E2040 / E2060 / E2080 | 20x40 / 20x60 / 20x80 | 矩形 |
| E3060 | 30x60 | 矩形 |
| E4080 | 40x80 | 矩形 |

- 尺寸表参考知名开源库 **NopSCADlib**（`extrusions.scad`，GPL-3.0）的公开
  行业尺寸，几何构造用 FreeCAD Part 布尔运算重新实现。
- 方形与矩形系列均已注册为可选型号，下拉中显示为如 `40x40 E4040`、
  `20x40 E2040`。
- **矩形截面方向约定**：截面第一个尺寸为「水平横向」，第二个尺寸为「竖直」。
  立柱：第一个尺寸沿框架 X、第二个沿 Y；X/Y 横梁：横向=第一个尺寸、竖直=
  第二个尺寸（如 20x40 的横梁为 20 宽 × 40 高）。

## 框架几何规则

```
坐标系原点：框架底面中心 (0, 0, 0)
Z 轴：竖直向上
框架外边界：X = ±L/2,  Y = ±W/2,  Z = [0, H]
```

- Z 立柱位于 4 个外角，柱外角与框架外角对齐
- X 横梁两端贴合 Z 立柱内侧面（梁长 = L - 2×截面宽度）
- Y 纵梁两端贴合 Z 立柱内侧面（梁长 = W - 2×截面宽度）
- 截面中心与立柱截面中心齐平（梁 Z 基线 = 0，不居中于截面高度）

## 连接方式与打孔

在任务面板的「**连接方式**」下拉中选择接头工艺，插件会按所选方式**在型材实体上真实切孔**，
并把攻丝规格、深度、孔位与连接五金写入 BOM（五金数量自动汇总）。

| 连接方式 | 型材加工 | 说明 |
|---------|---------|------|
| 角码 + T型螺母 | 不打孔 | 螺栓滑入槽内，BOM 输出角码/螺栓/螺母 |
| 端面攻丝 + 侧向贯穿 | 梁端攻丝 + 立柱贯穿 | 默认方式，最常用 |
| 隐藏式连接件 | 梁端攻丝 + 梁侧工艺孔 + 立柱贯穿 | 外观无外露件 |
| 打孔攻丝 | 梁端贯穿 + 立柱贯穿 | 配槽内螺母 |
| 锚式连接件 | 梁槽内锚孔 + 立柱贯穿 | 槽内装入锚件 |
| 直连接 / 连接棒 | 梁端攻丝 | 用于分段梁/柱同轴对接 |
| 脚座/顶板 | 立柱顶底端面攻丝 | 固定脚座与顶板 |

- 孔位按当前**截面方向**（立柱方向/横梁竖直）与层高自动计算。
- **攻丝规格按型材实际中心孔自动匹配**（中心孔即攻丝底孔）：E1515→M4、
  E2020/20x40/60/80→M5、E3030/30x60→M8、E4040/40x80/E4040t→M12；
  DXF 型材按解析出的中心孔直径匹配；实心方管按截面分档。
- **贯穿孔为间隙孔**（名义+约1mm，如 M12→Ø13.5），保证螺栓能穿过。
- **隐藏式/锚式工艺孔只钻单面**（顶面，深=半截面+1），不贯穿整个截面。
- **打孔攻丝**为梁端横向穿孔（垂直梁轴）+ 槽内螺母，立柱为间隙贯穿孔。
- 攻丝孔以底孔形式切出并在 BOM 中标注攻丝尺寸；当中心孔≈底孔时实体上无明显
  变化（属正常，攻丝不建模螺纹）。
- **开孔参数可在面板输入**：孔径/孔深/孔位距端（0=按型材推荐值）；其中**孔径
  上限 = 型材较小边尺寸的一半**，超出会被自动收敛（如 40x40 输入 Ø30 → Ø20）。
- **BOM 打孔说明含位置与方向**：攻丝注明「两端，每端1处，共2处/根」；打孔注明
  距端面距离、方向（沿梁轴/垂直梁轴/从顶面向下）、孔径、深度，立柱注明各层 z
  高度与每层孔数。

## TechDraw 加工图纸

勾选面板「生成 TechDraw 图纸」后，会创建**一张 TechDraw 页面**，把**每种型材规格**
（X-横梁 / Y-纵梁 / Z-立柱）各占一行：

- 使用内置 **A2 横向带边框模板**（`templates/A2_Landscape.svg`，594×420）：
  文字与视图均限制在内框（22mm 边距）内，并**避让右下角标题栏**；
- **所有文字标注左对齐**（中文界面）：注释内 ASCII 转全角（等宽），并给每块追加
  一条等长的横线使各块宽度完全一致，共用同一 X → X/Y/Z 左边缘精确对齐
  （实测均 22.01mm）；英文界面下注释本身为等宽 ASCII，直接对齐；
  （此前"导出实测反馈"方案会在 HLR 计算期间重算导致崩溃，已移除）
- **标题栏字段（中文标签）自动填写**：规格(如 `40x40 E4040`)、比例(如 `1:2.3`)、
  图号、材料、连接方式；数值写入每帧专用模板文件
  （`~/.cache/AlumFrame/A2_*.svg`），因此 TechDraw 页面本身与导出 PDF 都能看到；
  不再单独放置顶部标题；
- **所有型材使用同一比例**（由最长型材与行高共同决定），因此图面上可直接比较
  各型材长短；比例值标注在标题栏（如「比例 1:2.2」）；
- **所有型材一端对齐**（左端固定在图框 22mm 处），右端不超过内框；
- 超长型材主视图线宽自动变细；**端面视图为 1:1 细节图**，T 槽/孔在 20m 长时仍清晰；
- 「导出图纸 PDF」会把内容与模板合成，输出**带图框与标题栏**的 PDF；
- 已按 200 / 300 / 500 / 800 / 1000 / 1500 / 2000 / 3000 / 4000 / 6000 /
  8000 / 10000 / 15000 / 20000 mm 全长度段校验：不越界、左对齐、同比例；
- 每种型材按**最长边水平**摆放（X 视图不旋转，Y/Z 视图旋转 90°）；端面视图按
  同一比例绘制（必要时限幅以免超出）；
- **自动尺寸标注**（主视图上方、紧贴型材）：
  - 长度 = 两端面线间距（如 `1040`）；
  - 孔位只标一条尺寸链：**两端面→最近孔中心**（如 `20`/`20`）+
    **相邻孔中心距**（如 `230`/`230`），其余尺寸可由这些推出；
  - 尺寸数值创建后自动校验（`getRawValue` 与期望值比对，超差即删除）；
  - 子元素名通过 `getEdgeByIndex` / `getVertexByIndex` 直接解析（模型坐标），
    不依赖名字顺序猜测；标注位置做了 TechDraw 导出偏移补偿与图框/标题栏避让；
- 文字标注：部件、**规格、长度、数量**、材料、连接方式、**打孔方式**（孔位/方向/孔径/深度）；
- **图纸文字跟随界面语言**：标题栏（图名/规格/比例/图号/材料/连接）、注释、尺寸由
  `i18n.py` 输出中文或英文；英文界面下注释保持 ASCII 等宽对齐；

页面对象以 `TD_` 前缀命名，重建时按「先解绑视图 → 删视图 → 最后删页」的顺序安全清理。

## 打孔情况（默认端面攻丝方式）

### X-横梁 / Y-纵梁（水平梁）

**两端攻丝**：M6↔M12（按系列），每根梁 2 处（高端面 + 低端面），深度 = 1.5×直径。

### Z 立柱（竖柱）

**每层十字贯穿孔**：X/Y 向各一处，螺栓通过并用螺母锁紧。
**顶底两端攻丝**：固定脚座/顶板（选择「脚座/顶板」方式时生成）。

## 参数表（Parameters）

在 FreeCAD 中，每个框架生成一个 `Parameters` 电子表格，作为**单一数据源**：

| 单元格 | 含义 | 示例 |
|--------|------|------|
| B1 | 型材规格 | 20x20 |
| B2 | 型材宽度 (mm) | 20 |
| B3 | 外形长度 X (mm) | 600 |
| B4 | 外形宽度 Y (mm) | 400 |
| B5 | 外形高度 Z (mm) | 500 |
| B6 | Z 层数 | 1 |
| B7 | 材料 | Aluminum 6061 |

> 直接修改 B3（长度）等单元格 → 几何/标注实时更新，无需重新生成。
> 修改 Frame 组属性面板也会同步更新参数表（双向通道）。

## 安装

```bash
# 1. 将仓库克隆到 FreeCAD 插件目录（FreeCAD 1.1 用户目录示例）
git clone git@github.com:gdbdzgd/AulmFrame.git \
    ~/.local/share/FreeCAD/v1-1/Mod/AlumFrame

# 或者创建软链接（开发模式）
ln -s /path/to/repo ~/.local/share/FreeCAD/v1-1/Mod/AlumFrame
```

> 插件采用 FreeCAD **现代命名空间布局**（`freecad/AlumFrame/`，`init_gui.py`
> 入口，不修改 `sys.path`），需要 **FreeCAD ≥ 1.1**（见 package.xml 的
> `<freecadmin>`）。

重启 FreeCAD 后，工具栏/菜单出现以下 **铝型材框架** 命令：

| 命令 | 说明 |
|------|------|
| 新建框架 | 打开生成器，创建新框架（含型材型号、方向、连接方式、出图选项） |
| 编辑框架 | 读取选中/当前框架参数并原地重建 |
| 导出 BOM (CSV) | 把当前框架的 BOM（含打孔说明与连接五金）导出 CSV |
| 生成 TechDraw 图纸 | 为当前框架重新生成加工图纸（每规格一行，含数量与打孔方式） |
| 导出图纸 PDF | 导出带图框/标题栏的 A2 图纸 PDF |

> 修改插件代码后需重启 FreeCAD（或重新加载工作台）才能生效。

## 使用方法

### 新建框架

1. 打开 FreeCAD，切换到 **AlumFrame** 工作台
2. 点击 **New Frame** 按钮，输入参数，点击 OK
3. 框架几何 + BOM + 标注自动生成

### 编辑已有框架

1. 选中任意框架零件（梁或立柱均可）
2. 点击 **Edit Frame** 按钮（或菜单 AlumFrame → Edit）
3. 面板预填当前参数，修改后点击 OK 即原地重建

### 导出 BOM CSV

```python
from AulmFrame.bom import export_bom_csv
export_bom_csv(beams, '/tmp/bom.csv', material='Aluminum 6061',
               hole_spec={'beam_cross': 'M5', 'post_tap': 'M6'},
               profile_size=20)
```

## 界面语言

- 语言跟随 **FreeCAD 的语言设置**（`编辑 → 首选项 → 常规 → 语言`），
  包括任务面板、菜单、提示、**BOM 表格/CSV 内容**与**TechDraw 图纸文字**
  （注释、标题栏、尺寸标注）；
- 检测顺序：`FreeCADGui.getLocale()`（当前生效语言）→ `Language` 偏好
  （无界面/启动早期）→ 系统 locale（偏好留空时的 FreeCAD 行为）→ 中文；
  语言改动与其他 FreeCAD 界面一样，**需重启 FreeCAD 生效**；
- 非中文语言一律回退为英文（当前内置中/英两种文案）。

## 技术限制

- BOM 为静态文本，直接修改参数表后需通过面板"重建"刷新（走面板编辑时自动同步）
- 不支持部分立柱（4 立柱/整数层为固定拓扑）
- 下拉仅提供参数化标准系列与普通方管；DXF 轮廓型号已移除（解析代码保留参考）
- 参数化梁的基体是 `Part::Extrusion`（**草图驱动**）：截面草图在「Frame」组内，
  名为 `X-横梁 截面` 等，双击可用 Sketcher 编辑并联动所有阵列副本；
  连接孔用 `Part::Cut` 保存在基体之上，重算不会丢失
- 阵列源基体（`X-横梁(阵列源)`）默认隐藏，否则会在框架中间多出一根梁；要改形状
  请编辑上面的截面草图（或使用面板重建）
- 连接孔布尔结果 `XBeamBase_Cut` / `YBeamBase_Cut` / `ZPostBase_Cut` 及孔工具
  `*_Holes` 默认隐藏（仅为几何依赖，不参与显示）
- 连接方式的孔位参数为通用取值（如隐藏件侧孔距端 18mm、锚孔距端 15mm），可按
  实际五金在 `connections.py` 的 `params` 中调整
- TechDraw 投影计算复杂截面较慢，首次生成/重建图纸可能耗时数十秒
